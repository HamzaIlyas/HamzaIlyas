## Now

**[Stillwright](https://github.com/HamzaIlyas/stillwright)** · an open-source orchestrator that
runs inside Claude Code, Codex, Gemini CLI, Cursor and any agent that reads Agent Skills. It
plans goals, vets tools by reading their code, proves every step, and speaks only when it
needs you. One Rust binary, plain-file state, MIT.

```sh
pip install stillwright && npx skills add HamzaIlyas/stillwright
```
